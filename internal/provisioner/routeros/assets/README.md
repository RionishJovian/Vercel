# Router-local glass portal artwork

Owner-selected dark emerald glass reference, 2026-10-23. The wallpaper and dimensional Wi-Fi mark were generated with the built-in image tool specifically for this screen. The WebP delivery files were resized/encoded using cwebp, with alpha retained on the mark. They are bundled through go:embed and inlined into the shared preview/deployment document: no third-party asset URL, pre-login WAN request or router binary upload is needed.

- jade-portal-wallpaper.webp: 400 px wide; dark emerald optical-glass wallpaper with silver edges and muted violet/champagne edge lighting.
- jade-portal-wifi.webp: 128×128 px; transparent silver/emerald glass Wi-Fi symbol.

Keep original generation outputs in local task evidence; regenerate or replace assets deliberately rather than hotlinking an external image. RenderPortalLogin and its 24 KB bound are the release gate for the entire combined page, including branding and terms.
