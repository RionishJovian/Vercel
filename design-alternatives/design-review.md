# Mega Magic Liquid Glass previews

Completed 23 October 2026. Isolated visual prototypes; no production frontend, backend, account, router or payment changes.

## Directions

1. **Jade Glass — recommended starting point.** Mega Magic jade accents, a wide navigation sidebar, translucent window and distinct overview widgets. Balanced brand expression and readable operations.
2. **Nightfall.** Dark teal glass, panoramic navigation and a unified metrics strip. Stronger atmosphere; available in light mode too.
3. **Studio.** Compact icon rail, quieter surfaces and denser operational layout. Available in both appearances.

Each direction includes Overview, Internet Vouchers with search/status filtering, Create Batch dialog, print preview and a phone guest-login preview. Other navigation areas are explicitly disabled outside preview scope.

## Brand and assets

Uses the existing Mega Magic logo and existing local Lucide icon paths. Original AI-generated jade/seafoam/lavender silk wallpapers have coordinated light and dark assets. No Apple logos or Apple blue branding. Wallpaper toggle, appearance selection and reduced-effects control are included. Original Hermes drafts are retained in previous-hermes-drafts/.
