# MegaMagic logo — "Wi-Fi Spell" (proposal, 2026-11-13)

Wi-Fi and magic combined in one mark, at the owner's request: a wand casts the Wi-Fi signal.
- **The wand's star tip is the Wi-Fi dot.** It is a bright four-point star with a warm glow.
- **The three Wi-Fi arcs are spell light.** They run from gold near the wand to mint as the signal travels outwards. Each arc has a soft glow, a solid body and a bright core.
- **Magic dust sparkles along the arcs.**
- **The wand** is the polished pearl wand from the realistic proposal, with a dark tip, silver rings and a soft shadow. It sits on an emerald glass tile with a warm aura behind the star.

**Status: awaiting owner approval.** The app, web pages, icons and manifest still use the current logo. Two other proposals sit alongside this one as alternatives: `../megamagic-logo-signal-gem/` and `../megamagic-logo-realistic/`.
