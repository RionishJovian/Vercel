# MegaMagic logo — "Signal Gem" (original proposal, 2026-11-13)

An original mark created at the owner's request ("your own creation", not tied to the wand concept). It shows a brilliant-cut emerald from above, with a golden Wi-Fi beacon glowing in its table. Each element stands for something:
- The gem is MegaMagic's emerald, and the value of a network that runs well.
- The beacon is the Hotspot the product powers.
- The light through the facets is the magic.

The artwork is built from:
- an octagonal crown with kite, star and upper-girdle facets, shaded by a light from the upper left;
- pavilion reflections inside the table;
- a specular streak and a depth gradient;
- glowing white sparkles;
- a deep emerald tile.

**Status: awaiting owner approval.** The app, web pages, icons and manifest still use the current logo. The realistic wand proposal in `../megamagic-logo-realistic/` remains as an alternative.

- `megamagic-logo.svg`: vector master (512 × 512 viewBox).
- `megamagic-logo-512.png`, `-180.png`, `-64.png`: renders of the master with a transparent background.
- `megamagic-logo-review.png`: review sheet with the current logo next to the new one, real UI sizes, and the dark sign-in and header contexts.
- `make-logo.cjs`: the script that wrote the SVG. It is kept as a record only.
- `SHA256SUMS`: checksums. Once adopted, ship these exact files and check them against the sums. Do not regenerate or retouch them.
