# MegaMagic logo — realistic edition (proposal, 2026-11-13)

A realistic rendering of the approved logo A concept (wand with sparkling stars):
- an emerald glass tile;
- a tapered pearl wand with a dark polished tip;
- a faceted gold star;
- glowing mint and white sparkles.

**Status: awaiting owner approval.** The app, web pages, icons and manifest still use the current logo.

- `megamagic-logo.svg`: vector master (512 × 512 viewBox).
- `megamagic-logo-512.png`, `-180.png`, `-64.png`: renders of the master with a transparent background.
- `megamagic-logo-review.png`: review sheet with the current logo next to the new one, real UI sizes, and the dark sign-in and header contexts.
- `make-logo.cjs`: the script that wrote the SVG. It is kept as a record only.
- `SHA256SUMS`: checksums of the generated files.

The owner asked that the logo not be changed after generation. When it is adopted, ship these exact files and check them against `SHA256SUMS`. Do not regenerate or retouch them.
